# vcf2table

Универсальный инструмент для обработки VCF файлов (Variant Call Format), извлечения аннотаций и создания таблиц Excel с данными геномных вариантов. Поддерживает все референсные геномы, включая кастомные базы данных snpEff.

## Особенности

- **Полный конвейер анализа**: объединение, аннотирование VCF файлов и генерация Excel таблиц в одном инструменте
- **Поддержка любых геномов**: работает с любым организмом, поддерживаемым snpEff, включая кастомные базы данных
- **Автоматическое определение хромосом**: интеллектуальное сопоставление имен хромосом между VCF и референсными последовательностями
- **Многопоточная обработка**: оптимизирована для быстрой обработки больших файлов
- **Автоматическая загрузка данных**: автоматически скачивает таблицы признаков для выбранного референса
- **Подробная диагностика**: информативные сообщения для отладки проблем аннотирования

## Установка

### С использованием Conda (рекомендуется)

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ваш_пользователь/vcf2table.git
cd vcf2table
```

2. Создайте Conda-окружение из файла environment.yml:

```bash
conda env create -f environment.yml
conda activate vcf2table
```

### Зависимости

- Python 3.12+
- pandas, pysam, openpyxl, tqdm, cyvcf2, vcfpy
- snpEff 5.1+ (устанавливается через Conda)
- bcftools (устанавливается через Conda)

## Использование

### Полный анализ одной командой

```bash
python vcf2table.py all -v vcf_files/*.vcf.gz -o результат.xlsx -r Имя_Референса -p
```

Эта команда:
1. Объединит все VCF файлы
2. Автоматически сопоставит имена хромосом с референсным геномом
3. Аннотирует варианты с помощью snpEff
4. Извлечет аннотации в таблицу
5. Добавит информацию о вариантах из всех исходных VCF
6. Сохранит результаты в Excel файл

### Доступные команды

#### Команда `all` (всё-в-одном)

Выполняет весь процесс обработки за один вызов.

```bash
python vcf2table.py all -v vcf_files/*.vcf.gz -o результат.xlsx -r Mycobacterium_tuberculosis_h37rv -p -th 8
```

Параметры:
- `-v, --vcfs`: Список VCF файлов (.vcf.gz с индексами .tbi)
- `-o, --output`: Путь к итоговому Excel файлу
- `-r, --reference`: Референсный геном для snpEff (по умолчанию Mycobacterium_tuberculosis_h37rv)
- `--feature-table`: Путь к пользовательской таблице признаков TSV (необязательно)
- `-p, --progress`: Отображать прогресс выполнения
- `-th, --threads`: Количество потоков (по умолчанию 4)
- `-t, --temp`: Путь для сохранения временного VCF (по умолчанию удаляется)

#### Команда `extract`

Извлекает аннотации из аннотированного VCF в таблицу Excel.

```bash
python vcf2table.py extract -i input.vcf -o output.xlsx -r Escherichia_coli_K12 -p
```

#### Команда `update`

Обновляет существующую таблицу данными из VCF файлов.

```bash
python vcf2table.py update -v file1.vcf file2.vcf -t input.xlsx -o updated.xlsx -p
```

#### Команда `prepare`

Подготавливает и аннотирует VCF файлы.

```bash
python vcf2table.py prepare -i input1.vcf.gz input2.vcf.gz -o prepared.vcf -r Escherichia_coli_K12 -p
```

#### Команда `download-table`

Загружает таблицу признаков для указанного референса.

```bash
python vcf2table.py download-table -r Escherichia_coli_K12 -p
```

## Работа с кастомными геномами

vcf2table поддерживает любые референсные геномы, которые могут быть использованы snpEff, включая пользовательские базы данных.

### Использование существующей snpEff базы данных

Просто укажите имя базы данных:

```bash
python vcf2table.py all -v vcf/*.vcf.gz -o result.xlsx -r Yasnaya_Polyana -p
```

### Создание кастомной базы данных

1. Создайте базу данных для snpEff с помощью скрипта сборки:

```bash
./build_phage_db_conda.sh NC_054909.1 Yasnaya_Polyana
```

2. Запустите vcf2table с именем созданной базы данных:

```bash
python vcf2table.py all -v vcf/*.vcf.gz -o result.xlsx -r Yasnaya_Polyana -p
```

### Автоматическое определение хромосом

Инструмент автоматически определяет имена хромосом из базы данных и сопоставляет их с хромосомами в ваших VCF файлах. Это решает распространенные проблемы несоответствия имен хромосом.

## Диагностика неполадок

### Ошибка "ERROR_CHROMOSOME_NOT_FOUND"

Если вы видите эту ошибку в результатах, значит, имена хромосом в VCF не соответствуют именам в базе данных. Решения:

1. Убедитесь, что база данных правильно построена и содержит все необходимые файлы
2. Проверьте имена хромосом в файле sequences.fa базы данных
3. Запустите скрипт с подробным выводом `-p` для диагностики

### Ошибка "База данных не найдена"

Если snpEff не может найти базу данных:

1. Проверьте путь к директории данных snpEff
2. Убедитесь, что база данных построена и содержит файл snpEffectPredictor.bin
3. Перестройте базу данных с помощью команды:
   ```bash
   snpEff build -dataDir данные -gff3 -v Имя_Референса
   ```

## Примеры использования

### Исследование мутаций M. tuberculosis

```bash
python vcf2table.py all -v tb_samples/*.vcf.gz -o tb_mutations.xlsx -r Mycobacterium_tuberculosis_h37rv -p -th 16
```

### Анализ вариантов фага

```bash
python vcf2table.py all -v phage_samples/*.vcf.gz -o phage_variants.xlsx -r PhageGenome -p
```

### Объединение результатов секвенирования

```bash
python vcf2table.py all -v run1/*.vcf.gz run2/*.vcf.gz -o combined_results.xlsx -r Escherichia_coli_K12 -p
```
